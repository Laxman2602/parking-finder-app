# 🅿️ Parking Finder App

A full-stack web application that helps users find, book, and manage parking spots in real-time. Built with React, Node.js, and PostgreSQL.

## ✨ Features

### For Users
- 🔐 **Authentication** - Register, login, and password recovery
- 🔍 **Search Parking** - Find available spots by location, price, and availability
- 📍 **Real-time Availability** - See live parking slot status
- 🎟️ **Instant Booking** - Reserve parking spots instantly
- 📅 **Booking Management** - View, modify, or cancel bookings
- 👤 **User Dashboard** - Track your booking history and preferences

### For Admins (if implemented)
- 📊 **Analytics Dashboard** - View occupancy rates and revenue
- 🅿️ **Parking Management** - Add/edit/remove parking locations
- 👥 **User Management** - Manage registered users
- 📈 **Reports** - Generate usage and revenue reports

## 🛠️ Tech Stack

| Category | Technology |
|----------|------------|
| Frontend | React.js, Tailwind CSS, Axios |
| Backend | Node.js, Express.js |
| Database | PostgreSQL |
| Authentication | JWT (JSON Web Tokens) |
| Security | bcrypt, Helmet, CORS |
| Development | Vite, ESLint, Prettier |
